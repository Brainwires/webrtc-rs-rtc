## Not implemented / limits

| Area | What | Why |
|---|---|---|
| SDP numbers | `o=` ids, times and `b=` values must fit 64 bits | RFC 9429 5.2.1 keeps the ids within 63 bits anyway |
| SDP `c=` in a media section | Several lines are accepted; the last one is kept | Layered multicast only |
| SDP validation of remote descriptions | `SessionDescription::validate` exists; `set_remote_description` does not call it | Left to the JSEP work |
| Rejected remote m= sections | The application stops its own transceiver (the engine doesn't stop it for a rejected section in a remote offer) | Kept from wpt100's design |
