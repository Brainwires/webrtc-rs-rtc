# RFC 8838 conformance audit: Trickle ICE

Spec: RFC 8838, "Trickle ICE: Incremental Provisioning of Candidates for the Interactive
Connectivity Establishment (ICE) Protocol", January 2021 (current; not obsoleted). The SDP
encoding of trickle is RFC 8840 (SIP usage) and RFC 9429 (JSEP); only RFC 8838's own clauses are
audited here.

Audited at fork master 8916bc3. Code: `rtci-ice/src/agent/`, `rtci-ice/src/candidate/`,
`src/peer_connection/mod.rs`, `src/peer_connection/internal.rs`, `src/peer_connection/sdp/mod.rs`,
`src/peer_connection/transport/ice/`. All sections (3 to 18) are done.

Level `MUST*` marks a requirement the RFC states without a BCP 14 keyword ("the agent will",
"is set to"); it is counted as MUST. The engine is sans-I/O: the application gathers candidates
(`add_local_candidate`) and carries signalling, so "using protocol" clauses bind the application
and are `n/a` unless the engine's API is what makes them possible.

- SHOULD: tested 10 / untested 0 / partial 0 / missing 0 / violated 0 / n-a 3

## Gaps, in order of importance

1. **End-of-candidates is not wired to the agent** (14-3 violated, 14-2, 8-3, 13-6, 13-8, 13-10
   missing, 14-1 partial). Size M. Give the agent `set_remote_end_of_candidates()` and
   `set_local_gathering_complete()`; refuse remote candidates after the remote indication; refuse
   (or error on) local candidates after the local one and after nomination; let Checking become
   Failed as soon as every pair is Failed and both flags are set, and let the nomination wait end
   at the remote indication.
2. **No pair redundancy or limits** (10-4, 10-5, 10-6a, 10-6b, 11-3, 11-4, 11-4A, 11-5a, 11-5b,
   9-1). Size M. Prune pairs whose local base and remote address already have a pair (srflx
   replaced by base), only among Waiting pairs; replace a peer-reflexive remote candidate by the
   signalled one with the same address (taking its priority and type); cap pairs at 100, dropping
   Failed then lowest priority. Shared with RFC 8445 §6.1.2.4 / §6.1.2.5.
3. **Generation on trickled candidates** (9-3, 13-1, 18-5 partial). Size S. Put the local ufrag
   (and the mid) in `OnIceCandidateEvent` / `RTCIceCandidate::to_json`; emit a per-generation
   end-of-candidates event; drop a remote candidate without `usernameFragment` only when its line
   has a `ufrag` extension naming another generation.
4. **Frozen state / foundations** (12-3 missing, 12-1, 12-2 untested). Size L, shared with
   RFC 8445 §6.1.2.6: needs real checklists.
5. **Tests for what works by construction** (3-1, 5-1, 8-2, 13-2, 13-4, 13-7, 16-1, 17-3
   untested). Size S: a `can_trickle == Some(false)` case, an offer without `ice-options`, the
   local `a=end-of-candidates` line and event, half trickle end to end.
6. **Pairing before conveying** (10-1 partial). Size S: document it, or add an opt-in
   `mark_local_candidate_conveyed` and hold pairing until then.
